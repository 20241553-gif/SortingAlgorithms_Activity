Discuss the differences between the three sorting algorithms.
Ang difference nila tulo kay naa silay tagsa-tagsa nga gamit depende kung unsa ka gamay or kadako ang data, ug naa pud silay pros and cons. Ang bubble sort kay gamit siya for small arrays and dili siya compatible para mag sort ug large nga data. For selection sort, although minimum ra iyang swaps pero kailangan gyapon niya agian ang every data para ma-compare niya. And lastly, ang insertion sort, instead nga mag i-full swap niya ang tanan data, iya nalang i-insert sa iyang correct position, unlike sa bubble ug selection sort nga i-scan nila ang kada data and i-swap and i-repeat ang process hantod ma-sort ang tanan data.
